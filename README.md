# Xiaomi Scale Cloud · 米家体重秤云端报告

将米家云端称重报告同步为 Home Assistant 传感器。**无需 ESP32、蓝牙代理、bindkey 或单独运行同步服务。**

> 实验版。S400 Pro 自测支持，S400 推测支持，其他设备可自行选择测试。

## 使用效果

扫码登录米家账号，手动选择一台秤，即可为该设备上有称重记录的每个人创建一组传感器。以后出现新人员的记录，会自动补充实体。

    米家账号 → 手动选择设备
                 └─ 家里的秤
                     ├─ 刷新报告
                     ├─ 人员 A：体重、体脂率、最近测量时间……
                     └─ 人员 B：体重、体脂率、最近测量时间……

- 列出云端返回的**全部设备**，显示“米家名称 · 英文型号 · 设备 ID”，不按名字或型号筛选，不自动替用户选择。
- 一台秤添加一次；多台秤分别添加，人员数据按设备隔离，不跨秤自动合并。
- 每人 **22 个传感器**；每台秤 **1 个刷新报告按钮**。
- 默认每 **15 分钟**刷新，配置选项可调整为 5–1440 分钟。
- 直接使用云端报告数值，不重新估算体脂。缺失项目显示未知，未测量心率的零占位不显示为 0 bpm。
- 按云端档案标识分人，同名人员不会按姓名合并。检测到身份冲突则更新失败。
- 没有新报告时保留最近一次测量及其时间。网络失败时实体不可用；凭据失效时由 HA 提示重新认证。

## 前提与兼容性

- Home Assistant **2026.10.4 或更新版本**。
- 秤已添加到米家，且账号在所选地区能读取其云端称重报告。
- HA 能访问小米账号服务和米家云。
- 使用拥有设备及数据访问权限的账号扫码；共享设备的可见性和报告权限可能不同。
- 本集成不是小米官方集成，也不能复用官方 Xiaomi Home 集成的 OAuth 授权。

## 安装：HACS 自定义仓库

本仓库可作为 HACS 自定义集成仓库添加，**不是 HACS 默认收录项目**。

1. 打开 **HACS → 右上角菜单 → 自定义仓库**。
2. 填入仓库地址：https://github.com/Sowevo/ha-xiaomi-scale-cloud 。
3. 类型选择 **Integration / 集成**，添加后搜索 **米家体重秤云同步**（也可搜索 Xiaomi Scale Cloud）。
4. 下载集成，重启 **Home Assistant Core**。
5. 按下方“配置”完成扫码登录。

若菜单名称不同，以当前版本的“自定义仓库”入口为准。

## 安装：手动复制

1. 下载 [Releases](https://github.com/Sowevo/ha-xiaomi-scale-cloud/releases) 中的安装 ZIP，或下载仓库源代码。
2. 只把 custom_components/xiaomi_scale_cloud 文件夹复制到 HA 的 /config/custom_components/。
3. 最终路径必须是 /config/custom_components/xiaomi_scale_cloud/manifest.json，不要多套一层目录。
4. 重启 **Home Assistant Core**。

两种方式任选一种。用 HACS 安装后，后续版本也通过 HACS 更新。

## 配置

1. **设置 → 设备与服务 → 添加集成**，搜索 **米家体重秤云同步**（也可搜索 Xiaomi Scale Cloud）。
2. 选择米家账号所在地区。
3. 用 **米家 App → 扫一扫**扫描配置页二维码，在手机确认登录，再点 HA 页面的提交。
4. 从完整设备列表手动选择秤。请同时核对名称和英文型号，昵称不一定包含“秤”。
5. 集成先验证能否读取报告，成功后自动建立各人员的实体，不需要逐人配置。

二维码来自小米账号服务，不是秤的绑定二维码。过期可重新生成；页面提供官方登录链接作为备用入口。本集成不会重新绑定设备或修改米家里的人员档案。

找不到设备时先核对账号和地区。没有人员实体时，先用对应人员档案称重，并确认报告已同步到米家云。空档案不会生成实体。

### 错误提示

| 情况 | 行为 |
|---|---|
| 未返回称重记录 | 提示未找到记录，停留在设备选择页，允许重新选择 |
| 接口返回无法解析的数据 | 提示设备或报告格式可能不支持 |
| 网络请求失败 | 提示检查网络或稍后重试 |
| 登录失效或无权限 | 提示重新扫码登录 |
| 已添加同一台设备 | 提示设备已配置 |

仅凭“记录为空”不能认定设备不是秤，新秤或未同步的秤也可能没有记录。验证失败时不会创建空的体重实体。

## 传感器

体重、BMI、体脂率、脂肪量、肌肉量、肌肉率、骨骼肌量、身体水分率/量、骨矿物含量/比例、蛋白质率/量、内脏脂肪等级、基础代谢、身体年龄、身体评分、去脂体重、两项阻抗、心率，以及最近测量时间。

“最近测量时间”取自云端记录，不是轮询时间；设备时钟可能与 HA 接收时间有误差。最新报告缺失的字段显示未知，不沿用上一份报告的相应字段。

## 已知限制

- 读取路径是 **秤测量 → 米家同步云端 → 本集成 → HA**，不能替代离线蓝牙实时采集。
- 只发布每人的最新报告，不回填全部历史到 HA Recorder；之后的历史由 HA 自身配置决定。
- 首次加载及重启后扫描历史，最多 50 页，当前每页 20 条。超过上限仍未读完会明确失败，不把部分人员误报为全部成功。
- 后续轮询保留已知人员并读取近期记录。近期没有称重不会删除人员；删除云端人员后也不会自动清理 HA 实体。
- 新旧报告以共有的云端档案 accountId 关联，缺少时使用 user.id；不使用登录账号 uid 或姓名合并。歧义数据会更新失败。
- 云端接口非公开，可能随小米服务调整而需要维护。
- 旧版 0.1/0.2 采用逐人配置方式；升级前请备份，避免保留同一设备的多个旧配置项再重复添加。尚未提供旧版实体历史迁移保证。

## 隐私

不收集遥测，不向作者发送报告，不发送手机通知，也不唤醒秤。

小米登录密码不经过集成；会话凭据由 HA 保存在配置项中，HA 配置备份也可能包含凭据，请按账号资料保管。仓库和安装包不包含真实登录会话、二维码或私人报告。

反馈时请移除账号、姓名、设备 ID、token、cookie、二维码链接和原始报告等敏感内容。

## 开发

需要 Python 3.14，建议在独立虚拟环境内运行：

    python -m pip install "homeassistant==2026.10.4" "requests>=2.32.5" "pycryptodome>=3.23.0"
    python -m unittest discover -s tests -v

静态检查：

    ruff check --select F,E9 --exclude _vendor .
